# Мобильное приложение на Flutter/Dart с использованием паттернов Bloc и Cubit

В данном репозитории представлено небольшое мобильное приложение для хранения списка книг, написанное на языках программирования Flutter и Dart с использованием технологии Bloc/Cubit. 

Cubit представляет собой подмножество дизайн-паттерна BLoC, которое выступает в роле контроллера и позволяет через вызов функций со стороны вёрстки изменять данные приложения и посылать на вёрстку состояния. 

Bloc — это полноценный дизайн-паттерн, который в отличии от Cubit использует события (event), вызываемые через пользовательский интерфейс, вместо функций. 

**Итоговое приложение состоит из следующих окон (для каждого окна имеется 2 версии, одна использует Cubit и другая использует Bloc):**
- Основное окно вывода списка книг
- Окно создания новой книги
- Окно изменения данных книги
- Окно удаления книги
